# Character icons

Put one PNG per character in this folder, named with the character's id from
`src/data/roster.json`:

```
dr-mario.png   mario.png        luigi.png        bowser.png      peach.png
yoshi.png      donkey-kong.png  captain-falcon.png  ganondorf.png  falco.png
fox.png        ness.png         ice-climbers.png kirby.png       samus.png
zelda.png      sheik.png        link.png         young-link.png  pichu.png
pikachu.png    jigglypuff.png   mewtwo.png       mr-game-and-watch.png
marth.png      roy.png
```

The SmashWiki head icons are 24 × 24 pixels. The app shows them at exactly 1× (roster
tiles) and 2× (character panel) with pixelated scaling, so they stay sharp. Any character
without a file shows its first letter instead. Refresh the page after adding files.
